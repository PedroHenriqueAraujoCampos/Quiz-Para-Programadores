# Quiz Para Programadores

Projeto desenvolvido com HTML e CSS com o objetivo de criar um quiz interativo voltado para programadores e estudantes de tecnologia. O site apresenta perguntas relacionadas a desenvolvimento web, linguagens de programação e conceitos básicos da área.

## Preview do Projeto

O projeto possui uma interface simples, organizada e intuitiva, contendo:

- Perguntas de múltipla escolha
- Campos de texto
- Upload de arquivos
- Seletores
- Tabela de pontuação
- Área de feedback
- Lista de respostas
- Imagens e elementos semânticos do HTML

## Tecnologias Utilizadas

- HTML5
- CSS3

## Funcionalidades

- Quiz interativo sobre programação
- Utilização de diferentes tipos de inputs HTML
- Estruturação semântica da página
- Sistema de pontuação visual
- Área de feedback do usuário
- Exibição de respostas corretas
- Uso de imagens e tabelas
- Navegação simples e responsiva
